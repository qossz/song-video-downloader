# Android / Google Play status

The project in this repository is a Linux GTK application. It invokes yt-dlp for general YouTube audio/video downloads and spotDL for Spotify. It is not an Android project and has not been built or signed as an Android App Bundle.

Google Play's current intellectual-property policy gives streaming apps that let users save unauthorized local copies of copyrighted content as an example of prohibited functionality. YouTube Terms also restrict downloading except where the service permits it, the rights holder gives permission, or law allows it. This project has previously been used for well-known music searches, so submitting this unchanged would carry a substantial rejection and account-enforcement risk.

A Play-compatible Android version needs a different scope: use official YouTube playback/search capabilities and avoid extracting YouTube audio/video. Downloads should be limited to sources and media for which the user has the required rights and authorization. The current Linux version can remain separate.

Sources:
- https://support.google.com/googleplay/android-developer/answer/9888072?hl=en
- https://www.youtube.com/t/terms
