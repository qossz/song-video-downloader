# Third-party tools

This program invokes tools installed separately by the user:

- [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- [spotDL](https://github.com/spotDL/spotify-downloader)
- GTK, WebKitGTK, Zenity, FFmpeg, Node.js, and Mutagen

These tools are not copied into this repository. Each keeps its own license and terms. Check their official project pages before distributing a bundled build.
